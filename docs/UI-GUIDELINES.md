# UF Esports Hub UI Guidelines

## 1. Design Reference
We want the UF Esports Hub to have a clean and simple design that matches our UF Esports branding. We are using GitHub as a reference for things like spacing and consistency, but we want to keep our own style.

## 2. Colors
Our initial design uses a dark background with blue accents and light text.

These are the colors we plan to use:
- Primary Blue: #2962FF
- Background: #080B10
- Main Text: #F0F3FA
- Muted Text: #A0AEC0
- Borders: #202938
- Success: #1A7F37

We want to keep colors consistent across pages and make sure text is easy to read. We should also use text or icons along with colors to show things like errors and success messages.

These are proposed colors based on the landing page and should be checked against the actual frontend styles.

## 3. Fonts and Text
We will use common system fonts so the text looks consistent across devices.

Font: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif

- Page Titles: 24px
- Section Headings: 20px
- Body Text: 14px
- Form Labels: 14px
- Supporting Text: 12px minimum when needed

## 4. Spacing and Layout
We want to keep spacing consistent and use a layout similar to GitHub.

- 4px for small gaps
- 8px between related items
- 16px for normal spacing
- 24px between sections
- 32px for page spacing

Layout:
- Max content width: Around 1280px
- Mobile padding: 16px
- Desktop padding: 24px

## 5. Buttons and Inputs
- Keep button styles consistent.
- Make important actions easy to find.
- Include hover, focus, and disabled states.
- Give form inputs clear labels.
- Show messages when inputs are invalid or something goes wrong.

## 6. Navigation
- Keep navigation consistent across pages.
- Use clear names for links.
- Make it easy to tell which page you are on.
- Make sure users can navigate with a keyboard.

## 7. Desktop and Mobile
- Make sure the website works on desktop and mobile.
- Adjust layouts for smaller screens.
- Avoid content going off the screen.
- Keep forms and buttons usable on smaller devices.

## 8. Accessibility
- Aim for WCAG 2.2 AA contrast requirements.
- Normal text should have at least 4.5:1 contrast.
- Large text should have at least 3:1 contrast.
- Keep keyboard focus visible.
- Do not use color alone to show information.
- Check that text and UI elements are easy to see.
