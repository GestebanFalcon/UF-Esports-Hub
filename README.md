**Description**

UF Esports Hub is a website made to display, organize, and modify team data for campus esports organizations tailored towards UF Gator Esports.

**Project Details**

The project takes a monorepo layout using, shared, frontend, and backend folders.

**Frontend**
Vite React TS project - build using bun run build

**Backend**
Express TS project

## Contributing

Read [the code conventions](CONTRIBUTING.md) before making changes. They cover shared contracts, public serialization, project structure, readable code, and verification. Setup instructions live in the [shared](shared/README.md), [backend](backend/README.md), and [frontend](frontend/README.md) READMEs.
